## Executando localmente

### Pré-requisitos

- Node.js 16 ou superior;
- npm.

```bash
git clone https://github.com/TECHGAMESPI/portifolio.git
cd portifolio
npm install
npm start
```

A aplicação ficará disponível em `http://localhost:3000`.

## Build de produção

```bash
npm run build
```

Os arquivos otimizados serão gerados no diretório `build`.

## Estrutura principal

```text
public/
├── index.html       # Interface, conteúdo e interações principais
└── support.js       # Runtime utilizado pela interface

src/
├── components/      # Componentes da aplicação
├── img/             # Imagens do portfólio
├── info/            # Informações e conteúdos
└── index.js         # Entrada da aplicação
```
